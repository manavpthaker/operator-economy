# Reference catalog

This directory collects episode-agnostic material that helps an implementation agent understand the intended result. References are not independent sources of truth and do not override the authority chain below.

## Authority order

1. `../../../content-os/facts.md` for public facts and numbers.
2. `../../../content-os/flow.md` for release sequence.
3. `../../../content-os/rubric.md` and `../../../content-os/voice.md` for editorial evaluation.
4. `../../AGENTS.md` for OE repository boundaries.
5. `../../docs/blueprint-cinema.md` for canonical Blueprint Cinema creative direction.
6. `../../docs/blueprint-cinema-migration.md` for the migration decision and exclusions.
7. `../TOOLCHAIN.md` and `../PRODUCTION-TEAM.md` for department and tool ownership.
8. `../AGENTS.md`, `../ARCHITECTURE.md`, `../WORKFLOW.md`, and `../PORTING-POLICY.md` for the isolated production contract.
9. Files in this directory for detailed practice, nuance, and inspiration.

## Available references

- `CREATIVE-REFERENCE-STACK.md` identifies the useful production behavior in each external inspiration—including the pinned film-direction repositories—and the defaults or surface treatment OE should not copy.
- `EDITING-NUANCE.md` translates the creative direction into scene construction, motion, transition, footage, evidence, pacing, sound, and review principles.
- `DIRECTION-SYSTEM.md` defines the direction bible, rhythm map, look development, sequence treatments, shot boards, shot directions, continuity control, cognitive load, and prompt compilation.
- `SHOT-GRAMMAR.md` defines the episode-agnostic causal shot types used to show operations, proof, people, economics, failures, and outcomes without falling into animated-slide grammar.
- `SCENE-DIRECTION-CONTRACT.md` defines the two-pass director/build prompt compiler and exact shot-recipe requirements.
- `ASSET-MEDIA-CONTRACT.md` defines ticketing, candidate search, selection, rights, provenance, capture, B-roll, archival, AI plates, audio, manifests, local files, and technical checks.
- `EDIT-SOUND-FINISHING.md` defines edit construction, HyperFrames output strategy, Resolve handoff and conform, picture lock, Fusion, color, Fairlight, captions, online, and delivery.
- `REVIEW-QA.md` defines review evidence, severity, gate checklists, approval independence, and completion criteria.

## How to use references

- Read the reference that answers the current production question; do not load every document automatically.
- Borrow methods and decision criteria, never finished scenes, compositions, wording, graphics, music, or a channel's surface style.
- Treat external videos as visual studies, not assets.
- If a reference conflicts with the Blueprint Cinema canon, the canon wins.
- If a reference implies a factual claim, verify the claim through the episode's research and content-os rules before public use.
