# Review records

This folder holds the human-readable engine, world, visual-plan, greybox, agent-work, and implementation reports for the current fixture. Later edit and delivery reports remain future-gate artifacts.

Reports must distinguish authored, validated, approved, generated, rendered, and still blocked. They record exact hashes, checks, unresolved risks, and the next operator command. A report never advances state on its own.

The current reports reflect hash-bound approvals through `greybox_ready` and successful smoke renders. They do not record `greybox_approved` or any later state.
