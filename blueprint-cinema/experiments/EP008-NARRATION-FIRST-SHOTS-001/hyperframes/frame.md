# Boundary Ledger narration-first frame

## The frame

The frame establishes a stable world. Only the accountable change moves. Each shot has one primary
focal point, one visual sentence, one shot job, and one legible exit state.

## Composition rules

- Paper carries human context and unresolved work.
- Mineral carries accountable records and inspectable evidence.
- Steel carries rented capability, dependency, and the current route.
- Oxide marks one operator-controlled action or commitment, never general emphasis.
- Sage appears only for a verified state. Risk appears only for an actual sourced failure.
- Roughness stays inside the working model. Narration text, records, labels, and sources are typeset.
- Human reality, system mechanics, and proof may alternate, but a persistent object must bridge the cut.
- Use two to five meaningful objects unless a real evidence source legitimately fills the frame.

## Motion rules

- Use only establish, trace, route, interrupt, correct, return, pin, and settle.
- Bind each action to an exact narration word or pause.
- Default to a cut. Use a continuity move only when a persistent object or accountable consequence survives.
- No ambient drift, idle wobble, decorative pulse, camera float, transition-pack flourish, or motion for energy.
- Let a changed state settle and remain readable.

## Typography

Use display type for the episode’s one landed thought, heading type for structure, body type for human
language, and monospace only for timing, records, routes, or source context. Text labels or lands
meaning; it does not restate the full narration.

## Prohibitions

No gradients, glass, glow, generic icon clouds, full-world node maps, floating dashboard cards,
gold/cobalt legacy accents, fake interfaces, fake evidence, or sentence-by-sentence title cards.

## Reference ruling

The original episode may teach editorial restraint, decisive contrast, and evidence-hold behavior.
No distinctive composition, title, copy, claim, timing, scene assignment, identity, or finished asset
is copied. EP007’s experimental shot geometry is not a template and carries no approval here.
