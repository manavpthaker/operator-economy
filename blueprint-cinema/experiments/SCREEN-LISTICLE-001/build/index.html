When I built Grapevines for
myself, I already had all my
context. Getting that from
someone else was the big thing.
My first two companies,
I needed a dev team for the
software. Now I build it myself.
It started with a problem I
had. Then I talked to people
going through it.
That's still the most important
part, finding out where it
actually hurts for them.
I turn what I heard into a
plan before I build anything.
I'd built a voice profile too.
Nobody brought it up,
so I took it out.
Building it myself means I
can change it fast.
Knowing what to change still
comes from talking to people.
