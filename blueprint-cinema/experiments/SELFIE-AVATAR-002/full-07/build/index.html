Sometimes it's less work
to just do the task.
I can use AI to build
something that does it for me.
But if it breaks,
or the way I wanna do
the job changes,
I'm still the one who's
gotta go back and fix it.
Say I automate how I
organize files for a project.
If I'm still moving
folders around and
changing what goes
where, I've now gotta
update the automation as well.
For something I do all
the time, that might be
worth it.
But if it's an
occasional job and I'm
still figuring out how I
want it done,
I might be better off
leaving it manual for now.
You guys tell me,
what's something you've
deliberately kept doing
yourself because the
automation wasn't worth
looking after?
