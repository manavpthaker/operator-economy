# Creative correction

## Control 001 diagnosis

Control 001 proved the technical round trip: exact locked narration, frame-quantized media, HyperFrames-to-Resolve interchange, exclusive clip ends, clean-room checks, Resolve rendering, and rejection of a one-frame black flash. It failed the creative full-pass gate because five large opaque plates carried the sequence, graphic state changes substituted for filmed actions, and the outcome was asserted more strongly than it was physically demonstrated.

This experiment therefore starts from coverage rather than panels. Thirteen distinct moving source clips carry 882 of 912 picture frames. The only full-frame schematic interruption is a 30-frame suppression decision. Labels remain shot-bounded and subordinate. Permission, selection, judgment, return behavior, and the economic consequence are attached to observable actions.

## Hard correction rules

- No Control 001 picture or creative structure is reused.
- Default transition is a hard cut.
- Every shot has one editorial job and one dominant visual priority.
- The OTA is visible as first-stay acquisition, never as an adversary.
- Permission resolves before retained context or any outbound route.
- Suppression precedes human review; human review precedes the direct path.
- The outcome ends in a physical guest/operator action with a privacy-safe direct confirmation, not a title-card claim.
- Source limitations, including wardrobe and location mismatch, remain explicit in provenance and final review.

## Narrow technical ports

Only the exclusive-end-frame convention, clean-room URL scan approach, and Resolve render/log/export pattern may be re-authored after inspection. Each port is recorded with its Control 001 origin and hash in `manifests/finishing-manifest.json`; no creative file is copied.
