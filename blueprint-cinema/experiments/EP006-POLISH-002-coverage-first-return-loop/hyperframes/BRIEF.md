# BRIEF

## Intent

Create modular, shot-bounded editorial overlays for a documentary reconstruction. Graphics clarify operational order while moving footage remains dominant.

## Required components

Transparent overlays for: persistent brass key-tag match, `FIRST STAY / OTA`, `PERMISSION`, `STAY CONTEXT`, `HUMAN REVIEW`, direct route, privacy-safe direct confirmation, and the recurring disclosure `SYNTHETIC VISUALIZATION · INTERNAL TEST`. One opaque 30-frame suppression insert is permitted.

## Constraints

1920×1080, 30 fps, 912-frame root reference, locked local VO, local frozen fonts/media, no runtime network, no gradients/glow/particles/bounce/ambient drift, no narration-as-headline, and no invented interface or evidence. Text must survive a 480×270 review. Alpha edges must survive H.264 compression after Resolve compositing.
