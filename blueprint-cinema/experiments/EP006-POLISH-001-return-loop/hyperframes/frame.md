# Frame direction — OE Return Loop control

## Visual premise

Reality, system, and proof share one object and one directional grammar. The brass key tag always represents the completed stay. It does not become a memory object until permission resolves, and it never becomes a fabricated guest record.

Each frame has one dominant visual priority. The viewer follows a physical handoff, then a gate, then one decision at a time, then one route, then one earned outcome.

## Canvas and safe area

- Canvas: `1920×1080`, 30 fps.
- Safe area: top `65`, right `134`, bottom `65`, left `134` pixels.
- Primary label range: `44–60px`.
- Headline range: `72–108px`.
- Fixture/source warning: `26–34px`.
- Corners: square or `2px` maximum.
- Depth: flat; no shadows or glows. Reality plates may retain natural optical depth.

## Palette

Use only these recorded OE tokens:

- Paper: `#F5F0E6`
- Lifted Paper: `#FBF8F1`
- Paper rule: `#D8CFB9`
- Ink: `#1A1A1A`
- Secondary Ink: `#3C3A36`
- Muted Ink: `#6B675E`
- Schematic Navy: `#14263E`
- Drafting Blue: `#1F3A5F`
- Ledger Gold on dark: `#C4A45F`
- Ledger Gold on paper: `#7A5E24`
- Status Sage: `#7B9E87`, only after a genuine gate or final state resolves
- Suppression Red: `#9B3E2E`, only while a path is actively stopped

Per frame: Ink + Paper, or Navy + Paper, plus at most one semantic accent. Scene 3 changes accent across hard internal phases; it never shows gold, red, and sage simultaneously.

## Type

- Boska 700, local WOFF2: display and final thesis only, never below `72px` here.
- Zodiak 700, local WOFF2: editorial subheads `44–60px`.
- Supreme 400/500, local WOFF2: labels and supporting copy.
- Menlo system fallback: sparse technical/fixture warning where the canonical Fragment Mono file is not available locally. No render-time font fetch.
- Uppercase labels use restrained tracking; no kinetic word-by-word captions.
- One italic phrase maximum across the entire control; this control uses none.

## Reality plate treatment

- Natural 35–50mm documentary lens language; locked camera.
- Warm modest inn, wood, linen, brass, and directional window light.
- High-resolution still plates receive only restrained, deterministic motion: no more than a `1.025×` optical push or a `20px` continuity reframe over the full shot.
- Plate motion cannot substitute for generated video and will be disclosed as still-image animation.
- A thin vector contour may trace the key tag only to preserve the match cut; no decorative rotoscoping.

## System treatment

- Orthographic paper or schematic-navy field.
- Wires are hairlines; routes draw only when the narrated operation authorizes them.
- Gates have visible closed/open mechanics, not UI controls.
- Memory is a categorical `STAY CONTEXT` object with no personal data.
- Suppression is a physical stop: the ineligible token reaches a brick-red terminal bar and does not fade through it.
- `HUMAN REVIEW` stays unresolved until the operator’s visible physical action.

## Proof treatment

- Separate paper proof bench; no document simulation.
- The outcome object reads exactly `DIRECT RETURN / VISUAL TEST`.
- It also reads `NON-PUBLISHABLE FIXTURE · NOT EVIDENCE` at source-label size.
- Final frame preserves `FIRST STAY / OTA` and `NEXT APPROPRIATE STAY / DIRECT` with the same key tag pinned to the hotel-owned return line.

## Motion rules

- Default transition: cut.
- One designed transition: key-tag reality-to-system silhouette match.
- Every move denotes handoff, request, grant, conversion, qualification, stop, judgment, opening, route, or resolved consequence.
- Use deterministic, paused GSAP timelines and explicit `fromTo` values.
- Default easing is linear or restrained power-out; stops are step/hold.
- No ambient drift, bounce, elastic easing, automatic stagger, parallax, spin, orbit, or camera flight.

## Sound direction for Resolve

- Dialogue is primary.
- Six optional accents only: key-tag clack, paper/handoff movement, permission resolve, suppression stop, direct route, outcome confirmation.
- Add quiet inn room tone; no generic music bed.
- Do not sonify every route or label.

## Avoidance check

- No invented colors, unsupported typefaces, gradients, shadows, glass, glow, or rounded floating cards.
- No complete node map, platform mark, reservation document, contact profile, fake message, confirmation number, result, price, statistic, or personal identity.
- No crossed-out OTA route. The OTA path remains useful and visually secondary.
