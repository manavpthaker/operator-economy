# Selfie avatar format experiment

Private September 12 test requested by Manav: reuse the accepted V5 identity in vertical phone-camera talking-head settings at home, outdoors and in a cafe.

The three still previews use built-in image generation. The video tests use the accepted source portrait, complementary behavior references and a 7.5-second excerpt of the original accepted voice. They are separately generated settings, not literal animation of the preview stills.

All three native video generations completed. Native generated audio differs from the supplied original. The usual fal Sync v3 restoration was rejected before job creation because the account balance was exhausted; the other two restoration requests were not submitted.

The `voice-preview-*` files place the unchanged original voice over each native picture with trailing silence only. They are soundtrack comparisons with UNFINISHED lip sync, not completed restorations. Native generated versions remain separate. These are private review samples, not published footage, evidence of a real visit, or replacements for the accepted OE avatar/episode.

Open `comparison.html` through a local HTTP server to compare the three original-voice previews and access their native versions. Confirmed hosted preview links and technical checks live in each `audio-restoration/<setting>/VOICE-PREVIEW.json`.

Exact prompts, media source identifiers, source hashes and job IDs are in `run.json`. Large images and video remain under ignored `media/`.
