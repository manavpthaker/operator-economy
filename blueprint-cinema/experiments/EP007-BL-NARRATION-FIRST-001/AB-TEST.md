# EP007 directing A/B test

## Controlled variables

- Same locked narration and 7.74-second duration.
- Same 16:9 canvas, 24 fps, narration level, no music, no SFX, no captions, and no on-screen
  disclosure.
- Same portrayal and claim guardrails.
- Both use generated human context and remain non-production tests.

## Independent variable

- A: footage-first. Coverage evolved by diagnosing and editing existing generated clips.
- B: narration-first. Dramatic question, shot jobs, geography, action, focus, and cut were locked
  before any visual generation.

## Review questions

1. Which version makes “somebody finally looks” feel like scrutiny rather than conversation?
2. Which version keeps the owner competent while making her centrality felt?
3. Which version makes the question about the operation without answering it too early?
4. Which cut or focus change feels narratively motivated rather than added for variety?
5. Which version better earns the move into the rough operating model?

## Failure conditions

B fails if it reads as generic consultation, if the rack focus feels like a flourish rather than a
change in what is being inspected, if the owner appears confused or diminished, if continuity
breaks, or if the live action implies a sale, failure, or resolved answer.

Generation failures do not authorize redesign. The first two motion attempts are preserved because
they failed their predeclared gaze/focus actions. Start/end keyframes were then added to execute the
same locked plan; shot count, geometry, narrative jobs, and edit point did not change.
