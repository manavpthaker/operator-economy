# Boundary Ledger invariant register

This register prevents a web implementation detail from quietly becoming a cross-media brand rule.
The universal IDs correspond to [`semantic-core.json`](./semantic-core.json).

## Universal

| ID | Invariant | Failure example |
| --- | --- | --- |
| U-01 | One focal point; one active commitment | Two oxide paths compete in one frame |
| U-02 | Roles carry meaning; bindings carry values | Treating `#B5482F` itself as the brand idea |
| U-03 | Rough model, typeset institution | Handwritten captions or source labels |
| U-04 | Visual polish never upgrades evidence | A generated receipt presented as proof |
| U-05 | Motion changes state, then settles | Ambient drift or endless pulsing |
| U-06 | Text labels or lands meaning | Full narration duplicated as kinetic type |
| U-07 | Sound supports events, not claims | A confirmation chime implying verification |
| U-08 | Recompose across aspect ratios | Cropping a 3:2 model into 9:16 |
| U-09 | Represent the current route fairly | Depicting a useful dependency as a villain by default |
| U-10 | Stillness is an authored state | Adding motion whenever the speaker is talking |
| U-11 | Audio and visuals remain independently intelligible | Hiding a principal risk only in on-screen text |
| U-12 | Generated plates are not evidence | Using AI-created UI or documents as source material |

## Surface-specific bindings

| Surface | Binding | Why it is not universal |
| --- | --- | --- |
| Web episode feature | 16px docket overlap | It describes CSS geometry, not accountability over time |
| Mobile web | 24px gutters and full-bleed paper | Distribution UI and video safe areas differ |
| Static episode art | 3:2 complete master | Motion formats require landscape, portrait, and square recompositions |
| Browser | Keyboard focus and `prefers-reduced-motion` | Video needs alternate cuts/end states, not browser interaction |
| Long-form video | 16:9, frame rate, title-safe, fine-line limits | These depend on the delivery master |
| Social | 9:16/1:1 composition and UI collision checks | Platform chrome changes the practical safe area |
| Audio | Loudness, intelligibility, phase, and true peak | Color and page geometry have no audio analogue |

## Translation decisions

| Still/web rule | Motion/audio translation |
| --- | --- |
| The page stays composed | The world remains stable while one meaningful operation changes |
| The model stays rough | Temporal marks retain authored irregularity; no uniform wobble filter |
| The docket is attached by 16px | An accountable record enters once, attaches to its subject, and holds |
| Keep the complete 3:2 art | Preserve actors, current route, owned path, and consequence in a new composition |
| No photography as episode imagery | Documentary footage is valid in Reality World; Working Model remains the designed identity |
| One oxide path | One commitment event or thesis locus is active at a time |
| Small annotations may become texture | Secondary detail may fall away, but captions, evidence, and the causal relationship may not |
| Reduced motion removes transitions | Reduced-motion cuts preserve the same before state, operation, and after state |

## Change rule

A universal-role change requires an owner decision and a major Boundary Ledger version. A binding
change requires verification in the affected medium and can ship independently without redefining
the semantic core.
