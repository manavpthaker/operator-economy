# Boundary Ledger fonts

These WOFF2 files are package-owned copies of the exact font binaries already used by the OE site.
They were copied byte-for-byte from `site/public/fonts/` on 2026-09-02 so the Boundary Ledger
reference does not depend on a production-site path.

- Boska 700 normal and italic — display and wordmark.
- Zodiak 700 normal and italic — editorial headings.
- Supreme 400 normal and italic, plus 500 normal — body and interface.

The accountable-data face remains a system monospace stack because no Fragment Mono binary is
vendored in the repository. Font licensing and any public redistribution decision remain governed
by the repository's existing asset policy; this copy does not add new rights.
