01 / The Operator Canvas

The operating model behind every episode, published so you can judge it.

The Canvas isn't a bonus download. It's the model each episode is written from: who buys, what's sold, how delivery runs, what the evidence supports, and what the first bounded test is. The episode walks it in story order. The Canvas page lets you work through it and decide.

Five sheets, one decision

  1. Opportunity. See where value is trapped, and who pays to fix it.
  2. System. Know what has to run every week, and where judgment stays human.
  3. Evidence. Separate sourced facts from estimates and open questions.
  4. Economics. Judge where value could move, case by case, never blended.
  5. Guardrails. Learn without overcommitting: a bounded first test with stop conditions.

Every material claim carries a class

  • Observed. A sourced fact; the receipt names who reported it.
  • Parallel. Transferred from an adjacent model; the transfer is stated.
  • Modeled. An assumption with its arithmetic shown.
  • Unknown. An open question, kept visible with how it resolves.
