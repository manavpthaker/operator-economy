# EP006 Motion-System Audit

## Editorial premise

The relationship is copied, fragmented, and reclaimed. Motion should carry that argument across scenes instead of illustrating each sentence independently. This pass intentionally pushes scale, repetition, mirroring, interruption, and persistent diagrams further than the final edit may require.

## Episode-wide motifs

1. **The duplicate guest:** mirrored human footage and duplicated platform windows make the repeat-dependence problem physical.
2. **Platform gravity:** interfaces pull toward frame edges; the hotel path pushes back toward center.
3. **The broken handoff:** the guest journey persists across several lines, with ownership changing stage by stage.
4. **Forensic evidence:** documents arrive as bordered source objects; claims are revealed from the source rather than restated as decorative captions.
5. **The owned path:** scattered cards eventually lock into one continuous gold route.

## Editing rules

- A visual idea may span several coverage beats; a cut is not required merely because the transcript created a new row.
- Use text as an editorial object only: thesis, contradiction, consequence, or outcome. Never place the narration in a subtitle box.
- Website captures stay inside browser/device geometry unless a deliberate full-frame punch-in isolates evidence.
- Do not repeat the same platform capture in adjacent beats.
- Human footage earns graphic manipulation only when the manipulation expresses the argument.
- Placeholders remain conspicuous and descriptive until replaced; they never masquerade as finished motion.
