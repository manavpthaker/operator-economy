Narrative verdict: pass

### Episode-level story spine

`A real customer action enters one tool but dies before the next owner sees it -> smaller firms add more software and AI-capable steps -> the operator reveals that humans are the hidden integration and exceptions have no owner -> the operator maps and rebuilds one stable path with tests, observability, and human controls -> the workflow fails representative edge cases and the operator chooses what to automate, stop, or escalate -> the system either reaches a measured reliable handoff or proves the offer should be redesigned.`

### Recurring visual grammar

- Persistent object: one transaction token, such as a lead, intake request, approval, or invoice.
- System state: received, incomplete, valid, duplicated, routed, acknowledged, failed, recovered, handed off.
- Evidence objects: timestamp, field comparison, event log, alert, test case, runbook, access owner, baseline, and after-state measure.
- Human role: interview, judgment, exception handling, approval, and acceptance - never a decorative silhouette.
- Motion logic: movement only when the transaction changes state; interruption when it fails; branching when human judgment is required; no motion added merely to energize a static card.
