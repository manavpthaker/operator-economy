# Step 1: editorial

Status: approved V2 Step 1 v1.4 authority. V1.4 incorporates the tested v1.3 opening and voice controls and adds the Episode Investment Thesis, opportunity-to-build architecture, build-only editorial rule, and short public naming standard.

Step 1 turns one promoted opportunity into the exact business blueprint and spoken story the episode will teach. It owns the Operator Canvas, viewer promise, narrative architecture, episode outline, claims-to-language map, performance-ready script, and script lock.

Step 1 does not own narration generation, visual direction, footage sourcing, animation, editing, title and thumbnail production, publishing, or distribution.

## Entry condition

Do not create an episode workspace until all of the following are true:

1. Step 0 has issued a current promotion record with `Editorial development authorized: yes`.
2. The six reviewed Step 0 artifact hashes still match.
3. The research refresh date has not passed.
4. No factual, legal, permission, guest, access, or source blocker remains open.
5. The public-framing contract and caveats have been carried forward.

Step 1 consumes approved research. It does not silently reopen broad research. A material evidence gap returns to Step 0 as a bounded amendment request.

## Stage flow

```text
promoted Step 0 package
→ handoff verified
→ episode number assigned
→ editorial contract approved
→ Operator Canvas locked
→ Episode Investment Thesis approved at E3I
→ narrative spine approved
→ episode beat sheet approved
→ episode outline approved
→ voice-and-comedy map approved
→ script drafted and challenged
→ editorial voice conformed
→ script locked
→ narration handoff issued
```

## Required outputs

Every future episode must leave Step 1 with:

- A verified Step 0 handoff record.
- An approved editorial contract.
- A locked Operator Canvas.
- An approved Episode Investment Thesis separating the show, opportunity, operator, entry-wedge, and BUILD theses; recording the short spoken company name, plain explanation, precise internal operating definition, opportunity-to-build architecture, and evidence boundary.
- An approved narrative spine.
- An approved episode beat sheet separating the cold open, silent identity sting, fixed brand string, episode promise, context runway, central question, earned thesis, body functions, and ending callback.
- An approved episode outline.
- An approved voice-and-comedy map defining thesis, analogy, humor, contempt, evidence treatment, and cadence.
- A claims map tied to the Step 0 evidence package.
- A performance-ready final script with no unresolved placeholders.
- A clean performance read-through containing only the intended spoken words.
- An editorial-voice conformity report tied to the exact script, `voice.md`, and observed speech-profile hashes.
- A review-disposition log accounting for every independent finding.
- A script-lock record containing hashes and named approval.
- A narration handoff containing performance intent and pronunciation notes without changing the locked words.
